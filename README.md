# Wiki Privacy Extractor 

A lightweight, tracker-free tool to instantly extract Wikipedia articles into clean, local Markdown files. Perfect for privacy enthusiasts, offline reading, and building a local personal knowledge base (like Obsidian).

## Features
- **Zero Telemetry:** Communicates directly with the official Wikimedia API. No tracking pixels, cookies, or JS tracking scripts.
- **Offline Ready:** Saves articles directly to your drive as standard `.md` files.
- **Clean Layout:** Automatically strips out sidebars, footers, ads, and navigation clutter.

## Installation & Usage

1. Clone this repository:
   ```bash
   git clone https://github.com/brolookslikeanfish67-hub/A-wiki-web-scraper
   cd wiki-privacy-extractor
   ```

2. Run the script using Python 3:
   ```bash
   python main.py
   ```

3. Paste your Wikipedia URL when prompted and hit Enter. Your markdown file will generate instantly in the same directory.
